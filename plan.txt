# Four-Week Plan

## Week 1 — Setup & Data Preparation

**Goal:** Build the foundation and verify that the webcam + MediaPipe pipeline works.

**Tasks**

* Install Python 3.10 and create a virtual environment.
* Install all required libraries.
* Download the ISLRTC-referred Kaggle dataset.
* Explore the dataset (class count, image size, distribution).
* Test MediaPipe with your webcam and verify detection of all 21 landmarks.
* Write a script to extract 63 landmark features (21 × x,y,z) from each dataset image.
* Save extracted features to a CSV file.
* Perform basic EDA (missing values, class balance, sample visualization).

**Deliverables**

* Working MediaPipe landmark detector.
* Landmark CSV ready for training.
* EDA notebook with visualizations.

---

## Week 2 — Model Training & Evaluation

**Goal:** Train and evaluate gesture recognition models.

**Tasks**

* Split the landmark dataset into training and testing sets.
* Train a Random Forest model as a baseline.
* Train a Keras neural network (Dense → Dropout → Dense → Softmax).
* Compare both models.
* Generate:

  * Accuracy score
  * Precision/Recall/F1-score
  * Confusion matrix
  * Training & validation accuracy/loss plots
* Save:

  * `isl_model.keras`
  * `label_encoder.pkl`

**Deliverables**

* Baseline Random Forest results.
* Neural network with ~90%+ accuracy (if dataset quality permits).
* Saved trained model.

---

## Week 3 — Real-Time Recognition Application

**Goal:** Connect the trained model to a live webcam.

**Tasks**

* Load the trained model.
* Capture webcam frames using OpenCV.
* Detect hand landmarks with MediaPipe.
* Predict the sign in real time.
* Display:

  * Predicted letter
  * Confidence score
  * FPS
* Add a stability buffer (e.g., 15-frame consensus).
* Build words by committing stable letters.
* Integrate offline text-to-speech with `pyttsx3`.
* Add a confidence indicator (green/yellow/red).

**Deliverables**

* End-to-end real-time ISL recognizer.
* Word formation.
* Speech output.

---

## Week 4 — UI, Deployment & Documentation

**Goal:** Make the project polished and portfolio-ready.

**Tasks**

* Build a clean Streamlit interface.
* Show:

  * Live webcam feed
  * Landmark overlay
  * Predicted letter
  * Confidence
  * Current word

  * Clear button

**Deliverables**

* Complete documentation and demo.
